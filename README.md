# monkeypad ⌨️

A minimalist, distraction-free writing canvas with rich aesthetics, inspired by the theme collection and typing experience of Monkeytype and layout components similar to WordCounter.net.

## Features

- **187 Official Monkeytype Themes**: Access a massive list of color schemes with live, interactive preview states.
- **Synthesized Typing Sounds**: Four audio feedback profiles built natively using the Web Audio API (no external assets required):
  - *Mechanical*: Satisfying switch clacks.
  - *Typewriter*: Vintage key clacks and Return carriage slide + bell "ding".
  - *Bubble*: Satisfying soft pops.
  - *Digital*: Minimal, phone keyboard ticks.
- **Zen Mode**: Distraction-free layout that dims the header and stats bar while you focus on writing.
- **Word Goal Targets**: Define target word counts to track your progress via a subtle visual bar.
- **Typewriter Mode**: Centered vertical scrolling that keeps your current line of text in focus.
- **Command Palette**: Press `Cmd+Shift+P` (macOS) or `Ctrl+Shift+P` (Windows/Linux) to control themes, sound settings, fonts, and canvas sizes.

## Getting Started

1. **Install dependencies**:
   ```bash
   npm install
   ```

2. **Start the development server**:
   ```bash
   npm run dev
   ```

3. **Build for production**:
   ```bash
   npm run build
   ```
